Proyecto de Aplicación de Eventos de Música

1. Descripción

Este proyecto consiste en el desarrollo de una aplicación de eventos de música que permite a los usuarios explorar, comprar y gestionar entradas para diversos conciertos y eventos musicales. La plataforma está diseñada para ofrecer una experiencia intuitiva y enriquecedora, facilitando la búsqueda de eventos según categorías y proporcionando información detallada sobre cada evento.

2. Problemática

La organización y promoción de eventos musicales enfrenta varios desafíos, como:

* Falta de visibilidad para los eventos.
* Dificultad en el acceso a información clara y concisa.
* Procesos de compra de entradas complicados.
* Problemas para encontrar eventos de interés cerca de la ubicación del usuario.

Esta aplicación busca abordar estas problemáticas proporcionando una interfaz amigable y accesible, permitiendo a los usuarios descubrir eventos, acceder a información relevante y realizar compras de manera eficiente.

3. Funcionalidades Principales

  3.1. Página de Inicio

* Buscador: Permite a los usuarios buscar eventos específicos o similares.
* Menú de Categorías: Clasificación de eventos en conciertos de música, exhibiciones, espectáculos de pie, teatro, entre otros.
* Eventos de Tendencia: Presentación de eventos populares con tarjetas que incluyen imágenes, nombre de la banda, título del evento, lugar, fecha y precio.
* Eventos Cerca de Usted: Muestra eventos relevantes según la ubicación del usuario.

3.2. Página de Detalles

* Cards de Presentación: Imágenes y detalles del evento (banda, título, lugar, fecha, asistentes, etc.).
* Descripción del Evento: Información detallada con opción de "ver más".
* Valor y Localización: Precio de la entrada, ubicación del evento y botón para realizar la compra.

3.3. Página de Compra de Boleta

* Card de Evento: Imágenes y detalles de la boleta (artista, código de boleta, puerta, silla, fecha, hora y código de barras para acceso).
